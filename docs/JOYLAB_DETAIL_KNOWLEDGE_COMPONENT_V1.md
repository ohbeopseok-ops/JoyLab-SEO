# JOYLAB Detail Knowledge Component V1

Component: KnowledgeBridge

## Structure

Evidence
→ Framework
→ Related
→ Next

## Evidence
For pages with material factual claims.
Show:
- source title
- source type
- reference date
- primary/secondary classification
- link

## Framework
Show:
- framework name
- one-line definition
- target use
- CTA

## Related
Always show at least 2, recommend 3.

Priority:
1. same Hub
2. same Entity
3. same Framework
4. cross-domain Bridge

## Next
Always one primary next action:
- next Research
- Playbook
- Dashboard
- Case
- Framework

## SEO Rules

- internal navigation must use real SSR-visible <a href> links
- do not rely only on JS click handlers
- evidence anchor text must be meaningful
- editorial override is allowed over automatic recommendation

## Mobile

Order:
1. Evidence
2. Framework
3. Related
4. Next

Related is 1-column on mobile.
Next CTA is full width.
Do not force equal card heights.

## GOLD Conditions

- Related >= 2
- Next = 1
- Evidence >= 1 for factual pages
- Framework linked when available
- links are crawler-visible
- no orphan page
